Real compost piles, measured every hour.

What's in a reading

One row per bin, per hour.

Readings from a bin's sensors are averaged into hourly rows. The API and the bulk files return the same fields.

FieldType · unitWhat it means
bin_refstringA random reference for one bin. Stable across the dataset, never linked to an account.
countryISO 3166-1 alpha-2Where the bin is, at country level only. For example ID.
methodenumtakakura, bokashi or aerated_static_pile.
recorded_atISO 8601 · UTCStart of the hour the row covers.
temperature_cnumber · °CCore temperature of the pile.
moisture_pctnumber · %Moisture content. null when the probe dropped out.
oxygen_pctnumber · %Oxygen in the pile, 0 to 21.
co2_pctnumber · %Carbon dioxide in the pile.
nh3_relativenumber · 0–1Relative ammonia intensity. Not a ppm value.
mq135_composite_ppmnumber · ppmRaw MQ-135 gas sensor response. A composite signal, not clean CO₂.
stage_id, stage_name0–4 · stringThe composting phase the rule engine assigned to this hour.
faultsarray of codesConditions flagged in this hour, for example ANAEROBIC_RISK or MOISTURE_LOW. In the CSV they are joined with ;.
How we anonymise

Everything about the pile. Nothing about the person.

Removed
  • Names and email addresses
  • Bin names
  • Addresses and coordinates
  • Device MAC addresses and hardware IDs
  • Account, bin and device database IDs
Coarsened
  • Location becomes a country code
  • Time becomes hourly averages, in UTC
  • Several sensors in one bin become one row
Replaced
  • Each bin gets a random bin_ref
  • The reference can't be turned back into an account or address
  • Deleted accounts disappear from the next snapshot
Know your sensors

Read this before you publish.

MQ-135 is not a CO₂ meter

It reacts to ammonia, CO₂ and other gases at once, and drifts from unit to unit. Treat mq135_composite_ppm as a composite signal.

Ammonia is relative

nh3_relative runs from 0 to 1. It shows when ammonia rises and falls, not how much is present.

A tropical baseline

The pilot site sits at 24–32 °C ambient, so piles start near 28 °C and cool back to it. Expect higher floors than temperate data.

Phases are rule-based

Stage labels come from temperature bands plus the 24-hour trend, not lab analysis. Use them as a guide, not ground truth.

Phase definitions

The ranges behind every stage label.

Also returned by GET /research/stages, so your code can use the same numbers we do.
